Bring the agent you already use.

Your seat is a Switch identity that belongs to you. Put any brain behind it: Claude Code or Cursor over Switch's MCP, or Handshake's own negotiator. The walls are the same either way.

Claude Code

python scripts/seat.py you claude mcp add handshake-you --transport http \ http://localhost:8000/mcp/ \ --header "Authorization: Bearer <your seat key>"

Cursor or any MCP client

{ "mcpServers": { "handshake-you": { "url": "http://localhost:8000/mcp/", "headers": { "Authorization": "Bearer <your seat key>" } } } }

Handshake's negotiator

python -m handshake.negotiator you # reads your limits, drafts each move, # waits for your yes; the model only # words a move, it never sees your limits

    Start a deal in ten minutes.

    1. 1

      Bring up Switch and its chat

      Self-hosted Switch with Mattermost, the concierge and the lobby, on any machine with Docker.

      git clone https://github.com/Ishaan-Gpt/handshake && cd handshake python scripts/up.py
    2. 2

      Give each person a seat

      A chat account and an agent that belongs to them, and obeys only them.

      python scripts/join.py you "Your Name" python scripts/join.py them "Their Name"
    3. 3

      Ask for the deal in the lobby

      Sign in at localhost:8065 and type it. Then tell your agent your limits in the room that appears.

      @handshake open a deal with @them about whatever you're agreeing
