This runs Handshake's own terms parser and strategy in your browser. The real thing runs on Switch.

Bring your agent. Keep your limit.

claude mcp add handshake-you --transport http \ http://localhost:8000/mcp/ \ --header "Authorization: Bearer <your seat key>"
{ "mcpServers": { "handshake-you": { "url": "http://localhost:8000/mcp/", "headers": { "Authorization": "Bearer <your seat key>" } } } }
python -m handshake

Your seat key comes from python scripts/seat.py you. It reaches your rooms and the tables, and gets a 403 everywhere else.

Run it in ten minutes

git clone https://github.com/Ishaan-Gpt/handshake && cd handshake python scripts/up.py # Switch + chat, in Docker python scripts/join.py you "You" # a seat each python -m handshake # the agents

No Docker? python scripts/simulate.py plays a whole negotiation in a second.
