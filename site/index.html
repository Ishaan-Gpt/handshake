    Run your own deal

    Switch, Mattermost, both companies, their agents, rooms and rules, in one command on any machine with Docker.

    git clone https://github.com/Ishaan-Gpt/handshake cd handshake && python scripts/up.py python -m handshake.negotiator acme python -m handshake.negotiator globex
